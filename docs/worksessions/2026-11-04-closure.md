Labelled estimate from the model above: about $2,500 of minimum-session revenue per send cycle that does not happen, and the warm-network attention it relies on is perishable; a move announcement lands weaker the longer after the move it arrives.

The onboarding, holds and approvals built this session are untested by a real person until Lacey signs in; untested code rots in a way tested code does not.
